# OpenCrosshair v0.1.1

Small fix release on top of v0.1.0.

## Fixed
- The app no longer opens a console (cmd) window when launched.
- The window and taskbar icon use the full-resolution application icon.

## Downloads
- `OpenCrosshair-0.1.1-setup.exe` - installer (per-user, no admin needed)
- `OpenCrosshair-0.1.1-portable-win64.zip` - portable build
- `SHA256SUMS` - checksums

## Known limitations
Still not verified on a real Windows 10 machine by the author: overlay click-through, focus behaviour, DPI scaling, multi-monitor, tray and autostart. Exclusive-fullscreen games cannot show the overlay and some anti-cheat systems may block it. The executable is unsigned, so Windows SmartScreen may warn on first run.
